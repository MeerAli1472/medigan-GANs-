# Medical Image Generation & Segmentation Pipeline

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![PyTorch](https://img.shields.io/badge/PyTorch-1.10%2B-orange)

A demonstration of using synthetic medical images to enhance deep learning models when real annotated data is scarce.

## Overview

This project showcases:
1. **Synthetic Image Generation** using Medigan's pre-trained GAN models
2. **Polyp Segmentation** with DeepLabV3 transfer learning
3. **Interactive Dashboard** for medigan models demonstration

## Colab Demo

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/MeerAli1472/medigan-GANs/blob/Main/Dashboard-app.ipynb)

The interactive dashboard allows you to:
- Generate different synthetic images in real-time
- Visualize generated images
- Experiment with different medigan models

## Key Features
- 🏥 Medical-grade synthetic image generation
- 🔍 DeepLabV3 segmentation of polyps
- 🖥️ User-friendly Gradio interface
